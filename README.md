# Koya Adaptive AI Player

Experimental Discord/game AI companion for authorized testing environments.

## Included

- `index.html` — project landing page
- `terms.html` — Terms of Service
- `privacy.html` — Privacy Policy
- `cloudflare-worker.js` — minimal Cloudflare Worker health endpoint

## Safety

Use only official Discord application/bot interfaces and game APIs that you are authorized to access. Do not automate ordinary Discord user accounts or bypass platform controls.
