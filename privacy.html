Privacy Policy

Last updated: September 3, 2026

1. Information processed

The project may process technical information required to operate an authorized integration, such as Discord identifiers, supported bot messages, game state, configuration and AI decision context. The exact data depends on how you deploy the project.

2. Purpose

Data is used to provide game-state observation, planning, memory and authorized execution features, troubleshoot the service and improve the beta.

3. Retention

Persistent game memory may be retained for the duration of a configured session or deployment. Operators should configure storage and deletion according to their requirements.

4. Third parties

If configured, information may be sent to third-party AI, hosting or API providers. Review those providers' privacy terms before enabling such integrations.

5. Security

Do not place passwords, API keys, authentication tokens or other secrets in source files, prompts, logs or public repositories. Use appropriate secret storage.

6. Contact

For questions about a particular deployment, contact the person or organization operating that deployment.
